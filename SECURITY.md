# Security Policy

## Reporting Security Vulnerabilities

HeroBM takes the security of our platform and user data seriously. If you believe you have discovered a vulnerability, security flaw, or privacy issue, please let us know immediately.

### How to Report

Please **do not** report security vulnerabilities via public GitHub issues, pull requests, or public forums.

Instead, submit your findings directly to our security team at:
📧 **support@herobm.com**

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue (proof of concept scripts, HTTP requests, or screenshots).
- Affected versions, components, or endpoints.
- Any potential remediations or mitigation suggestions.

### Our Commitment

When you report an issue privately:
- We will acknowledge receipt of your report within 2 business days.
- We will provide an estimated timeline for remediation.
- We will notify you once the fix has been validated and released.
- We ask that you maintain responsible disclosure and refrain from publicly discussing or publishing details until a fix has been deployed.
