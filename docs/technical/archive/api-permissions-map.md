# API Permissions Map

This document maps all API controller endpoints in `apps/api/src` to their respective HTTP methods, Casbin Resources, and Casbin Actions. It was generated by automatically scanning every single controller file.

## Exceptions / Skipped Endpoints
- **`auth.controller.ts`**: Uses `@SkipCasbin()` to allow login and token operations.
- **`telemetry.controller.ts`**: Uses `@SkipCasbin()` for unauthenticated frontend error telemetry (`POST /telemetry/client-errors`).
